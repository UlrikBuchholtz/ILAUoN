
# Introduction to Linear Algebra

This is the source code repository for the online textbook *Introduction to Linear Algebra*.

The published version of this edition is at <https://ulrikbuchholtz.dk/ila/>.

Modern tooling is being introduced on the migration branch. See
[`migration/phase2/README.md`](migration/phase2/README.md) for the locked,
independent demo and HTML/print build, and [`MIGRATION.md`](MIGRATION.md) for
decisions and evidence. The modern root project currently builds the hard-case
pilot, not the whole book. `DEVELOP.md` describes the retained legacy publisher.

You might want to submit a comment or suggestion using the Issues tab at the top of the page.

Have a look at `DEVELOP.md` if you are interested in contributing.
